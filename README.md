# 🎯 Juego del Ahorcado - TPI Metodologías Ágiles

**Trabajo Práctico Integrador** desarrollado para la materia **Metodologías Ágiles** de la carrera de **Ingeniería en Sistemas de Información**.

## 📖 Visión del Producto
Desarrollar una versión interactiva del clásico "Juego del Ahorcado" aplicando marcos de trabajo ágiles (Scrum) y prácticas técnicas (Extreme Programming). El objetivo no es solo lograr un juego funcional, sino mantener un entendimiento compartido en el equipo, maximizar la entrega de valor en ciclos cortos mediante el uso de un Story Map y asegurar la calidad técnica del incremento.

## 🚀 Estado del Proyecto
El desarrollo del producto se organiza mediante un **User Story Map** y entregas iterativas progresivas:

- [x] **Slice 1 (MVP):** Versión jugable básica (palabra aleatoria, validación de letras, dibujo del péndulo/muñeco, victoria/derrota). Incremento funcional para entrega temprana.
- [ ] **Slice 2 (Release 2):** Gestión básica de usuarios, niveles de dificultad y visualización del historial de letras intentadas.
- [ ] **Slice 3 (Release 3):** Selección de categorías, sistema de pistas limitadas y ranking de puntuaciones.

## 🛠️ Metodología y Herramientas
- **Marco de trabajo:** Scrum (Sprints iterativos enfocados en la inspección y adaptación).
- **Gestión del Backlog:** GitHub Projects (utilizado como tablero para dar seguimiento a las User Stories).
- **Prácticas XP:** Base técnica del proyecto para asegurar calidad.
